# ResuCraft AI — Testing Strategy & Verification Suite

ResuCraft AI enforces comprehensive automated testing covering unit, component, integration, machine PDF extraction, and end-to-end user journeys.

---

## 1. Test Suite Summary

- **Total Automated Tests:** 68 passing tests across 15 test files.
- **Coverage Distribution:**
  - `@resucraft/shared`: 14 tests (Zod schema validation, n-gram tokenization, skill dictionary, scoring formulas).
  - `@resucraft/api`: 10 tests (Health telemetry, AI gateway safety, Resumes concurrency sync).
  - `@resucraft/web`: 44 tests (IndexedDB store, ATS template rendering, PDF vector parsing, Job alignment UI, AI bullet modal, Better Auth, Cloud sync indicator, Conflict resolution, and Homepage launch).
- **Zero Flakiness:** All tests execute deterministically without real network calls or third-party API dependencies.

---

## 2. Test Execution Commands

### Run All Monorepo Tests (Vitest)
```bash
npm test
```

### Run Tests for a Specific Workspace
```bash
# Shared library tests
npm test --workspace=@resucraft/shared

# Backend NestJS tests
npm test --workspace=@resucraft/api

# Frontend Next.js tests
npm test --workspace=@resucraft/web
```

### Run Playwright End-to-End User Journeys
```bash
npm run test:e2e --workspace=@resucraft/web
```

## 3. Test Layers & Methodologies

### Layer A: Domain & Schema Validation (Vitest)
- Validates that malformed or incomplete resumes are rejected with helpful Zod error messages.
- Tests that unknown custom fields in JSON Resumes are preserved safely.

### Layer B: Machine PDF Extraction Suite (`pdf-parse`)
- **Objective:** Verifies that PDFs generated by `@react-pdf/renderer` are actually ATS-friendly.
- **Verification points:**
  - Extracts raw binary streams into text using `pdf-parse`.
  - Asserts that 100% of candidate names, positions, and bullets are extractable.
  - Verifies that section headings appear in logical top-to-bottom reading order.
  - Generates multi-page test resumes to confirm zero clipping or text loss across page breaks.

### Layer C: Deterministic Alignment Engine
- Evaluates fixed fixtures against technical job descriptions.
- Confirms that synonyms (e.g. `TS` ➔ `TypeScript`) match accurately while avoiding false positives.
- Validates the 70/30 mathematical weighting between required and preferred qualifications.

### Layer D: Component & UI Interaction (React Testing Library)
- Uses jsdom and `@testing-library/react` to test reactive user interaction.
- Mocks browser IndexedDB using `fake-indexeddb`.
- Tests modals, tabs, custom metric injection into `[X%]`, and sync status indicator toggling.

### Layer E: End-to-End User Journeys (Playwright)
Located in `apps/web/e2e/user-journeys.spec.ts`:
- **Journey 1:** Anonymous resume creation, editing, and preview update.
- **Journey 2:** Job description alignment modal calculation.
- **Journey 3:** Optional account modal and local-first guarantee verification.
